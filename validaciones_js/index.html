Guía paso a paso: formulario con validaciones en JavaScript

Aprende cómo está construido el formulario de registro de estudiantes, desde la estructura de carpetas hasta la validación y el envío.

1. ¿Qué son las expresiones regulares?

Una expresión regular (o regex) es un patrón que permite comprobar si un texto tiene una forma determinada. En JavaScript se comprueba con el método .test():

const cumple = /^\d{6,10}$/.test("123456");

En este ejemplo, cumple será true porque el texto contiene entre 6 y 10 dígitos. Estos son algunos elementos que aparecen en los patrones del proyecto:

SímboloSignificado
/.../Delimita el patrón en JavaScript.
^Indica el inicio del texto.
$Indica el final del texto.
\dRepresenta un dígito del 0 al 9.
\sRepresenta un espacio en blanco.
.Representa cualquier carácter, salvo un salto de línea.
+Indica una o más repeticiones.
{6,10}Indica entre 6 y 10 repeticiones.
[A-Z]Representa una letra mayúscula de la A a la Z.
(?=...)Comprueba una condición sin consumir caracteres.
!Niega un resultado: !patron.test(texto) significa que el texto no coincide.

El proyecto usa patrones para documento (/^\d{6,10}$/), teléfono (/^\d{10}$/), correo y contraseña.

Estas expresiones son comprobaciones sencillas para el ejercicio. No sustituyen la validación del servidor ni cubren todas las reglas posibles de esos formatos.

2. Validación en tiempo real

La validación en tiempo real responde a los cambios del campo mientras la persona escribe. El evento input se dispara cuando cambia el valor de un campo de texto. Para una lista desplegable y una casilla de verificación, el proyecto usa el evento change.

document.getElementById("nombre").addEventListener("input", validarNombre);

Cada función validadora devuelve true si el valor es válido y false si no lo es. También escribe o limpia el mensaje de error del campo.

3. Agregar validaciones para los demás campos

El archivo js/validaciones.js repite el mismo patrón: obtiene el valor, comprueba una regla, muestra o limpia el error y devuelve un booleano.

CampoRegla del proyecto
Nombre y apellidosAl menos 3 caracteres, ignorando espacios externos.
DocumentoEntre 6 y 10 dígitos: /^\d{6,10}$/.
CorreoForma sencilla texto@dominio.extensión, sin espacios.
TeléfonoExactamente 10 dígitos: /^\d{10}$/.
EdadNúmero entre 18 y 60, inclusive.
ContraseñaAl menos 8 caracteres, una mayúscula y un dígito: /^(?=.*[A-Z])(?=.*\d).{8,}$/.
ConfirmaciónNo puede estar vacía y debe coincidir con la contraseña.
ProgramaDebe seleccionar una opción distinta del valor vacío.
TérminosLa casilla debe estar marcada (checked).

Los campos de texto usan input; el programa y los términos usan change. La confirmación también se valida cuando cambia la contraseña, para mantener ambos valores sincronizados.

Construir el formulario y sus campos

El formulario agrupa los campos y permite escuchar un único evento submit. Cada campo tiene una etiqueta vinculada mediante for e id y reserva un elemento <small> para el mensaje:

<div class="grupo">
    <label for="nombre">Nombre</label>
    <input type="text" id="nombre">
    <small id="errorNombre"></small>
</div>

6. Construcción completa, campo por campo

Ahora construiremos el contenido del form en el mismo orden del proyecto. Para cada campo, agrega primero su HTML y luego el bloque JavaScript que lo valida. Los id deben coincidir exactamente entre ambos archivos.

Paso 1: nombre

Agrega el control y el espacio para su mensaje dentro del formulario:

<div class="grupo">
    <label for="nombre">Nombre</label>
    <input type="text" id="nombre">
    <small id="errorNombre"></small>
</div>

En JavaScript, comprueba que tenga al menos tres caracteres y ejecuta la función al escribir:

// BLOQUE 1. VALIDAR NOMBRE
function validarNombre() {
    const nombre = document.getElementById("nombre").value.trim();
    const errorNombre = document.getElementById("errorNombre");

    if (nombre.length < 3) {
        errorNombre.textContent = "El nombre debe tener mínimo 3 caracteres.";
        return false;
    } else {
        errorNombre.textContent = "";
        return true;
    }
}

document.getElementById("nombre").addEventListener("input", validarNombre);

Paso 3: documento

<div class="grupo">
    <label for="documento">Documento</label>
    <input type="text" id="documento">
    <small id="errorDocumento"></small>
</div>
// BLOQUE 3. VALIDAR DOCUMENTO
function validarDocumento() {
    const documento = document.getElementById("documento").value.trim();
    const errorDocumento = document.getElementById("errorDocumento");

    // ! significa NOT (negación): indica que el patrón NO se debe cumplir.
    // / / delimitan la expresión regular.
    // ^ indica el inicio del texto.
    // \d representa un dígito del 0 al 9.
    // {6,10} indica que debe tener entre 6 y 10 dígitos.
    // $ indica el final del texto.
    // .test() comprueba si el documento cumple el patrón.

    if (!/^\d{6,10}$/.test(documento)) {
        errorDocumento.textContent = "Ingrese un documento entre 6 y 10 números.";
        return false;
    } else {
        errorDocumento.textContent = "";
        return true;
    }
}

document.getElementById("documento").addEventListener("input", validarDocumento);

En /^\d{6,10}$/, \d significa dígito y {6,10} limita la cantidad a entre seis y diez. Los símbolos ^ y $ exigen que el texto completo siga el patrón.

Paso 4: correo electrónico

<div class="grupo">
    <label for="correo">Correo electrónico</label>
    <input type="text" id="correo">
    <small id="errorCorreo"></small>
</div>
// BLOQUE 4. VALIDAR CORREO
function validarCorreo() {
    const correo = document.getElementById("correo").value.trim();
    const errorCorreo = document.getElementById("errorCorreo");

    // ^ indica el inicio del texto.
    // [^\s@]+ permite uno o más caracteres que no sean espacios ni arrobas.
    // @ exige que exista una arroba.
    // [^\s@]+ exige caracteres después de la arroba, sin espacios ni otra arroba.
    // \. exige un punto después del dominio.
    // [^\s@]+ exige caracteres después del punto.
    // $ indica el final del texto.
    // .test() comprueba si el correo cumple el patrón.
    // ! niega el resultado: si NO cumple, muestra el error.

    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(correo)) {
        errorCorreo.textContent = "Ingrese un correo electrónico válido.";
        return false;
    } else {
        errorCorreo.textContent = "";
        return true;
    }
}

document.getElementById("correo").addEventListener("input", validarCorreo);

El patrón requiere texto antes y después de @, un punto en el dominio y ningún espacio. Es una comprobación básica de formato.

// BLOQUE 6. VALIDAR EDAD
function validarEdad() {
    const edad = parseInt(document.getElementById("edad").value.trim());
    const errorEdad = document.getElementById("errorEdad");

    if (isNaN(edad) || edad < 18 || edad > 60) {
        errorEdad.textContent = "La edad debe estar entre 18 y 60 años.";
        return false;
    } else {
        errorEdad.textContent = "";
        return true;
    }
}

document.getElementById("edad").addEventListener("input", validarEdad);

parseInt() convierte el texto en un número entero. isNaN() permite detectar si no se obtuvo un número.

// BLOQUE 7. VALIDAR CONTRASEÑA
function validarContrasena() {
    const contrasena = document.getElementById("contrasena").value;
    const errorContrasena = document.getElementById("errorContrasena");

    if (!/^(?=.*[A-Z])(?=.*\d).{8,}$/.test(contrasena)) {
        errorContrasena.textContent = "Mínimo 8 caracteres, una mayúscula y un número.";
        return false;
    } else {
        errorContrasena.textContent = "";
        return true;
    }
}

document.getElementById("contrasena").addEventListener("input", validarContrasena);

Los fragmentos (?=.*[A-Z]) y (?=.*\d) exigen una mayúscula y un dígito; .{8,} requiere al menos ocho caracteres.

    <small id="errorConfirmar"></small>
</div>
// BLOQUE 8. CONFIRMAR CONTRASEÑA
function validarConfirmar() {
    const contrasena = document.getElementById("contrasena").value;
    const confirmar = document.getElementById("confirmar").value;
    const errorConfirmar = document.getElementById("errorConfirmar");

    if (confirmar === "" || confirmar !== contrasena) {
        errorConfirmar.textContent = "Las contraseñas no coinciden.";
        return false;
    } else {
        errorConfirmar.textContent = "";
        return true;
    }
}

document.getElementById("confirmar").addEventListener("input", validarConfirmar);
document.getElementById("contrasena").addEventListener("input", validarConfirmar);

La confirmación se valida al escribir en cualquiera de los dos campos. Así, si la contraseña original cambia, también se vuelve a comprobar la coincidencia.

7. Validar el formulario y manejar el envío

La función validarFormulario() llama a todos los validadores y combina sus resultados. El manejador enviarFormulario(event) llama a event.preventDefault() para evitar que el navegador envíe o recargue la página antes de verificar los campos.

Si todo es válido, se muestra el mensaje de registro exitoso, se reinicia el formulario, se limpian mensajes y estilos y se deshabilita el botón. Si hay campos inválidos, sus validadores muestran los errores. El botón también se deshabilita cuando validarFormulario() encuentra errores.

Este es el bloque que reúne las diez funciones. Colócalo después de los validadores:

// BLOQUE 11. VALIDAR TODO EL FORMULARIO
const formulario = document.getElementById("formulario");
const btnRegistrar = document.getElementById("btnRegistrar");
const mensajeFinal = document.getElementById("mensajeFinal");

function validarFormulario() {
    let resultado = true;

    if (!validarNombre()) resultado = false;
    if (!validarApellidos()) resultado = false;
    if (!validarDocumento()) resultado = false;
    if (!validarCorreo()) resultado = false;
    if (!validarTelefono()) resultado = false;
    if (!validarEdad()) resultado = false;
    if (!validarContrasena()) resultado = false;
    if (!validarConfirmar()) resultado = false;
    if (!validarPrograma()) resultado = false;
    if (!validarTerminos()) resultado = false;

    btnRegistrar.disabled = !resultado;
    return resultado;
}

Por último, evita el envío tradicional si hay errores y muestra el resultado si los datos son válidos:

// BLOQUE 12. ENVIAR FORMULARIO
function enviarFormulario(event) {
    event.preventDefault();

    if (validarFormulario()) {
        mensajeFinal.textContent = "¡Estudiante registrado correctamente!";
        mensajeFinal.style.color = "green";
        formulario.reset();

        const campos = document.querySelectorAll("input, select");
        for (let i = 0; i < campos.length; i++) {
            campos[i].classList.remove("error", "exito");
        }

        const mensajes = document.querySelectorAll("small");
        for (let i = 0; i < mensajes.length; i++) {
            mensajes[i].textContent = "";
            mensajes[i].className = "";
        }

        btnRegistrar.disabled = true;
    }
}

formulario.addEventListener("submit", enviarFormulario);

La validación al escribir mejora la experiencia, pero no reemplaza la comprobación al enviar. En una aplicación real, el servidor también debe validar los datos, ya que las validaciones del navegador pueden omitirse.
