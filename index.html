1. ¿Qué es un array?

Un array (arreglo) es una estructura que permite guardar varios valores dentro de una sola variable. Los elementos se organizan en posiciones llamadas índices. El primer índice siempre es 0.

Ejemplo

let frutas = ["Manzana", "Pera", "Mango"];

console.log(frutas[0]); // Manzana
console.log(frutas[1]); // Pera
console.log(frutas[2]); // Mango
Índice Valor
0 Manzana
1 Pera
2 Mango
Importante: para acceder al primer elemento se utiliza frutas[0], no frutas[1].

Crear arreglos

// Array vacío
let nombres = [];

// Array con datos
let edades = [18, 20, 25, 30];

// Array de textos
let ciudades = ["Medellín", "Cali", "Bogotá"];

Agregar elementos

El método push() agrega un elemento al final del arreglo.

let colores = ["Azul", "Rojo"];
colores.push("Verde");

console.log(colores);
// ["Azul", "Rojo", "Verde"]

Recorrer un array con for

El ciclo permite visitar cada posición del arreglo. Se inicia en cero y se repite mientras el índice sea menor que la cantidad de elementos.

let animales = ["Perro", "Gato", "Conejo"];

for (let i = 0; i < animales.length; i++) {
    console.log(animales[i]);
}

En cada repetición, i representa la posición que se está consultando.

2. Métodos y propiedades principales

Elemento ¿Para qué sirve? Ejemplo
push() Agrega al final. nombres.push("Ana")
pop() Elimina el último elemento. nombres.pop()
splice() Elimina o reemplaza elementos por posición. nombres.splice(1, 1)
length Devuelve la cantidad de elementos. nombres.length
includes() Comprueba si existe un valor exacto. nombres.includes("Ana")
indexOf() Devuelve la posición; si no existe, devuelve -1. nombres.indexOf("Ana")
find() Devuelve el primer elemento que cumple una condición. numeros.find(n => n > 10)
forEach() Ejecuta una función por cada elemento. nombres.forEach(...)

Arreglos de objetos

Un arreglo también puede almacenar objetos. Cada objeto agrupa propiedades relacionadas.

let productos = [
    { nombre: "Teclado", precio: 50000 },
    { nombre: "Mouse", precio: 35000 }
];

console.log(productos[0].nombre); // Teclado
console.log(productos[0].precio); // 50000

Array de textospush()for

Enunciado

Desarrolla una aplicación web que permita registrar nombres de personas. Cada nombre ingresado debe almacenarse en un arreglo y mostrarse en una lista dentro de la página.

  2. Crear un botón para agregar el nombre.

Archivo js/ejercicio1.js 

let listaNombres = []; // Crear un arreglo vacío

let formulario = document.getElementById("formulario");
let inputNombre = document.getElementById("nombre");
// Sin .value para poder modificar después el input.
let lista = document.getElementById("lista");
let cantidad = document.getElementById("cantidad");

// Evento del formulario.
formulario.addEventListener("submit", function(event) {
    event.preventDefault();
    let nombre = inputNombre.value.trim();

    if (nombre === "") {
        alert("Ingrese un nombre");
    } else {
        listaNombres.push(nombre);
        mostrarNombres();

        inputNombre.value = "";
        inputNombre.focus();
    }
});

// Función para mostrar los nombres.
function mostrarNombres() {
    lista.innerHTML = "";

    for (let i = 0; i < listaNombres.length; i++) {
        lista.innerHTML += `<li>${listaNombres[i]}</li>`;
    }

    cantidad.textContent = `Total registrados: ${listaNombres.length}`;
}
Prueba: registra al menos cinco nombres. Comprueba que la lista se actualice y que la cantidad coincida con los nombres agregados.

Archivo js/ejercicio2.js

// Arreglo donde se guardan los números ingresados.
let listaNumeros = [];

// Referencias a los elementos del formulario y los resultados.
let formulario = document.getElementById("formulario");
let numero = document.getElementById("numero");
let lista = document.getElementById("lista");
let suma = document.getElementById("suma");
let promedio = document.getElementById("promedio");
let mayor = document.getElementById("mayor");
let menor = document.getElementById("menor");

// Agrega el número ingresado cuando se envía el formulario.
formulario.addEventListener("submit", function(event) {
    event.preventDefault();
    if (numero.value.trim() === "") {
        alert("Ingrese un número");
    } else {
        let valor = parseFloat(numero.value);

        listaNumeros.push(valor);
        numero.value = "";
        mostrarResultados();
    }
});

function mostrarResultados() {
    lista.innerHTML = "";

    let total = 0;
    let numMayor = listaNumeros[0];
    let numMenor = listaNumeros[0];

    for (let i = 0; i < listaNumeros.length; i++) {
        lista.innerHTML += `<li>${listaNumeros[i]}</li>`;
        total += listaNumeros[i];

        if (listaNumeros[i] > numMayor) {
            numMayor = listaNumeros[i];
        }

        if (listaNumeros[i] < numMenor) {
            numMenor = listaNumeros[i];
        }
    }

    let media = total / listaNumeros.length;

    suma.textContent = `Suma: ${total}`;
    promedio.textContent = `Promedio: ${media.toFixed(2)}`;
    mayor.textContent = `Número mayor: ${numMayor}`;
    menor.textContent = `Número menor: ${numMenor}`;
}
Ten en cuenta: inicializa el mayor y el menor con el primer elemento del arreglo. Además, no calcules el promedio si el arreglo está vacío.
Prueba: ingresa 10, 5, 20 y 15. Verifica que la suma sea 50, el promedio 12.5, el mayor 20 y el menor 5.

Requerimientos

  1. Crear campos para el nombre, el precio unitario y la cantidad.

  3. Validar que el precio sea un número finito mayor o igual a cero.
  4. Validar que la cantidad sea un número entero mayor que cero.
